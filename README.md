# 滚装配载台

面向滚装船配载审核员。按有效车位、轴距和轴载计算参考点两侧净弯矩，超局部轴载或超总矩时隔离。复算后按配载单核对独立清单，查看单据证据和差值，再登记复核结论。

## 启动

```sh
docker compose up --build
```

默认访问 http://localhost:18283。
打开工作台，点击运行即可使用内置的班次样例。选择导入可以换成自己的来源与独立账 CSV。
样例在 `sample_data/`，`shift.csv` 有分页表头、冲突修订、坏行、空值哨兵与业务拒绝，`external.csv` 有单边与数值差异。
端口可通过 `APP_PORT` 覆盖。运行记录和复核历史保存在 `ledger` 卷。

## 操作

- 在甲板复核展开业务证据，核对原始字段与计算项。
- 在隔离裁决逐行检查原因。同修订冲突按争议字段逐项选择来源行，核清后车辆放行计入，未采信来源列入抑制。独立对账按键对比外部账并列出差值。
- 在批次复算重跑当前输入。在交付复核提交带版本意见，并导出证据包。
